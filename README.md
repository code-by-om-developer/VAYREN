# VAYREN

A modern fashion e-commerce website focused on clean design, seamless browsing, and a premium shopping experience.

## Overview

VAYREN is a fashion and streetwear e-commerce project built to explore modern web design, responsive layouts, and interactive shopping experiences. The goal is to create a polished digital storefront with a strong visual identity and a user-friendly interface.

## Features

- Modern fashion-focused UI
- Responsive website layout
- Product browsing and product detail pages
- Shopping cart interface
- Organized asset and product structure
- Interactive elements powered by JavaScript

*Features are being developed as the project progresses.*

## Tech Stack

- HTML5 — structure
- CSS3 — styling and responsive layouts
- JavaScript — interactivity and functionality
